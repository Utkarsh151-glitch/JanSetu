# Known limitations - local development, 16 October 2026

- The local catalog now contains the original nine manually reviewed portals and evidence-gated IGOD listings. Exact live bundled, pending, state/UT and sector counts are in [CATALOG_COVERAGE.md](CATALOG_COVERAGE.md) and [DISCOVERY_RUN_REPORT.md](DISCOVERY_RUN_REPORT.md). This is not a comprehensive count of websites in India. Organization identities may still include uncertain duplicates; multiple landing pages can share a host.
- NIC reproduction permission is pending. Directory additions are local development data; the public-release validator blocks their distribution. A directory listing and an HTTP response do not establish independent ownership, content freshness, service availability or successful transactions.
- Missing/invalid URLs, robots restrictions, TLS failures, access restrictions, unexpected redirects and uncertain external operators remain in review. A timeout or error is not proof of permanent failure, fraud or retirement. Checks are dated observations from this machine; there is no continuous monitoring.
- LGD state IDs and public state-wise district/local-body aggregate counts have been obtained for all 36 states/UTs. Individual district/local-body IDs require CAPTCHA-protected exports and remain unlinked. See [administrative reconciliation](ADMINISTRATIVE_COVERAGE_RECONCILIATION.md). District and municipal coverage follows actual IGOD listings, not a guessed website for every administrative unit. Automated data.gov.in collection stopped at its robots restriction. The National Portal directory did not expose a complete independently usable result set in this environment.
- There are 52 source-reviewed service-information records after Phase 3C, plus two source-backed portal guides with JanSetu Hindi explanations. Of 54 additional investigations, 27 were published; 31 service cases remain pending, including the four older unresolved operations. Eligibility is unknown for 37 services and document lists for 23; populated lists can be partial. Published regional services cover five states/UTs, with no published district/local service. Modes: 24 online public entries, nine assisted and 19 information-only. No completed transaction, live integration or nationwide service coverage is implied. Website listings do not inherit service eligibility or transaction compatibility. Directory-listed records have not received individual UX or ownership audits. See the reproducible coverage and gaps reports.
- Search uses a local cached index with aliases and metadata-supported sector, level, state/UT and district filters. Results render lazily and computation runs off the Android UI thread. Classification is based on source categories and conservative name rules; confidence and source authority remain separate. Broader search relevance studies and reviewed service-intent mappings remain open.
- Hindi navigation, catalog management, privacy policy, curated descriptions and both guides exist. Independent translation review, complete locale/number formatting and extension localization remain open. Source organization names are preserved. Phase 3A service bodies remain in English and identify this limitation alongside Hindi controls. Official regional names are retained where supplied; no generated translation is treated as official metadata.
- The National Portal has a limited in-app WebView and reversible text zoom; other portals use the external browser. TLS-error simulation, authentication, payments, downloads/uploads, cross-host redirects and multiple-device compatibility remain unverified.
- Chrome renders catalog results in bounded batches. Logic and rendered-panel smoke tests use real catalog data and mocked extension APIs; installed toolbar/side-panel behavior remains unverified. The extension can no longer change any page: the NSP Readable text pilot, its stylesheet, its `scripting` permission and its route listener were removed in Phase 17 (18 October 2026). It cannot improve government server speed or redesign application forms.
- Android accepts newer signed local catalog files and can restore its bundle, without another APK installation. The extension still requires repackaging/reloading. The resumable source/state/category CLI, cache, review export and incremental local refresh exist; remote updates, scheduled operations, backend and admin accounts do not. A compact runtime catalog and pinned ECDSA-signed manual update format are implemented; there is no automatic fetch or remote revocation. Development key access is controlled by the local OS account. Production trust-key handling and permitted reuse remain unresolved.
- Tests and measurements from the actual expanded catalog are recorded in [QA_REPORT.md](QA_REPORT.md). The API 37 emulator is the only tested device. Broader accessibility/device testing, browser failure paths, deeper security testing, production signing, hosted privacy policy and Play publication remain open; consult the latest QA section for specific checks actually performed. The native integration framework has zero configured government providers. Unsigned release builds are local artifacts.


## Phase 3B local tracker

My Applications is device-only and stores user-maintained status, not government confirmation. It has no cloud sync, backup or key recovery (a user-initiated, unencrypted JSON export was added in Phase 10); uninstall/data clearing/device or key loss can lose records permanently. Inexact reminders depend on notification/channel permissions and Android power/force-stop behavior and are not guaranteed delivery. Tracker screens are currently English; the navigation label follows the app language. Full spoken accessibility, physical-device/OEM scheduling and production privacy review remain. See [tracker report](APPLICATION_TRACKER_REPORT.md).

## Phase 5 redesign and branding (17 October 2026)

- The redesign, logo, launcher icon, splash, illustrations, motion and settings were verified on one API 37 emulator (1080x2400, 420dpi) in light and dark, at 2.0x text on a 320dp-wide display, and in landscape. Android 8–14 devices were not tested. That includes the pre-Android-12 launch window and edge-to-edge status/navigation bars.
- Accessibility Test Framework checks pass on the main redesigned screens. The default validator does not capture screenshots, so colour contrast is supported by computed palette ratios, not rendered-pixel measurement. Manual TalkBack speech, physical-keyboard focus order and Switch Access remain unverified ([manual checklist](PHASE5_MANUAL_CHECKLIST.md)).
- Hindi strings added in Phase 5 are JanSetu's own wording and have not had an independent translation review. Service details and My Applications remain English, and Settings says so. Home task shortcuts search with English terms, so the search field shows English text even when the UI is Hindi.
- "Larger text in JanSetu" applies a linear 1.15x factor, capped at 2.0x overall. While it is on, Android 14's non-linear font scaling is not used for JanSetu text. Official websites are unaffected.
- "Reduce motion" removes JanSetu's own decorative and transition motion. Standard Material component feedback (ripples, switch thumbs, menus) follows Android's animation scale instead.
- The reminder notification's new bridge icon and teal accent have not been observed on a delivered notification. Delivery testing remains a Phase 4 gate.
- All brand and illustration artwork is original and documented in [asset credits](PHASE5_ASSET_CREDITS.md). It has not had a trademark search or legal review, which is needed before public release.

## Phase 7 My Documents (18 October 2026)

- Documents are local only. There is no account, sync, recovery copy or backup. Losing the Keystore key, uninstalling or clearing storage loses them. On key loss the encrypted files are kept, but they cannot be decrypted.
- There is no in-app lock. Anyone using the unlocked phone can open JanSetu and view documents. Screens are hidden from screenshots and recents. An optional device-unlock gate is a Phase 14 item.
- Deleting one document cannot guarantee erasure from flash storage. "Remove all documents" deletes the key, so remnants cannot be decrypted.
- File-picker access was tested with the API 37 emulator's DocumentsUI only. OEM pickers, Android 8–14 and real browser upload fields on live government sites are unverified (blocker RB-10).
- Prepare documents lists only recorded requirements, and those lists may be partial. 23 of 52 services record no document list and offer no checklist.
- The vault screens are in English.
- The code keeps a password-protected PDF without a preview, but no test covers that path.
